## 本轮交付

### 1. 从进程内粗限流补到共享模型准入

- `model-guard.ts`：Redis REST + 单条 Lua 原子预约，统一 IP 配额、全站 24h/30d 次数和并发租约。用 Redis TIME，所有 key 共用 cluster hash tag。
- 默认 IP 每小时 60 次（IPv6 按 /64，IPv4-mapped IPv6 归并）、全站 24 小时 40 次、30 天 1,000 次、3 个在途预约。窗口从第一次预约起算，**不是自然日/月或严格滑动窗口**。
- 生产/Preview 缺存储配置、超时或错误：停止模型调用；精确 FAQ 仍可降级。禁止生产 local 模式，不把共享存储故障变成无限调用。
- 失败/不确定结果不退还调用次数；12s 模型期限、30s 崩溃租约过期，finally 主动释放。REST 不自动重试，避免重复预约。
- Redis 只存 HMAC 后的访客标识，不存原始 IP 或对话。不能把次数上限说成金额上限，也不能保证供应商在收到取消后停止其内部计算。供应商硬预算仍必需。
- 客户端移除网络/网关错误的自动 POST 重放；只对明确 413 拒绝缩短历史再试。真实断网和 503 模拟均验证只有一次请求并保留手动重试。

### 2. CSP 与真实发布门禁

- 现代 Astro 页面启用构建哈希 CSP，限制脚本、事件处理器、connect、frame、form 等。保留必要的 inline style 属性；历史 HTML 附件不改写，只受平台基础头保护。
- 新门禁发现 `ThemeInit` 的 `is:inline` 未自动注册哈希，确实会被阻止。改为精确内容哈希注册，并逐页验证所有可执行内联脚本的哈希，不是放宽到 unsafe-inline。
- Vercel 构建改成 `npm run release:check`，官方依赖审计也会阻止发布。网络审计失败不跳过。GitHub 增加真实隔离 Redis 原子配额集成测试。
- 第一份 Preview 构建因为供应商单元测试继承 Vercel 环境、未隔离准入模块而失败。修复测试依赖隔离后重新构建成功，没有绕过测试。
- 发布脚本检查实际状态/安全头、404、历史跳转及目标页、feeds/sitemap、API 坏 JSON/大请求/方法错误。受保护 Preview 使用已登录 Vercel CLI，不公开 bypass secret，也没有关闭部署保护。
- 平台 308 在自定义安全头前产生，因此单独校验跳转目标，安全头在目标文档验证；没有错误地要求重定向带文档 CSP。

### 3. 外链、首页图片与可访问性

- 对构建内容中的 **413 个唯一外部地址**执行只读检查：250 可访问，58 返回 404/410，105 不确定（鉴权/限流/超时等不能叫“死链”）。只是可达性，不证明网页内容真实或安全。
- `external-link-health.json` 保存带日期快照。6 个当前项目入口暂停作为可点击按钮展示，说明“公开入口暂不可用”；项目状态/介绍与原 URL 均保留，GitHub 404 不被解释成仓库不存在。
- 历史链接仅在编译结果添加检查日期/HTTP 状态，不改 `src/content/posts` 或 `public`。后续扫描也复查快照中的暂停入口，便于发现恢复。
- 首页原有截图增加构建时 360/640/960 宽度 WebP，首图 high priority，取消运行时图片代理依赖。`src/assets/projects` 是已有截图副本，原图及历史 URL 保留，没有生成虚假产品图。
- Lighthouse 额外提示品牌导航可见文字与 aria-label 不一致；移除冗余覆盖名称，并在浏览器回归中显式启用该 axe 规则。不能只看 Lighthouse 总分。
- 打印修复深色 token、未滚动 reveal、复制按钮与过渡动画问题。Chromium 实际输出 3 页 A4 PDF，已逐页渲染查看：标题、正文、代码清楚，无导航/聊天遮挡。
