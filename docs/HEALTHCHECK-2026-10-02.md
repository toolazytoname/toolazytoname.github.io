## 确认的问题与已实施修复

### P1 — 聊天在开发环境不能挂载

**事实**：浏览器点击浮动按钮，先出现 `$RefreshSig$ is not defined`。依赖树中 Astro 使用 Vite 8，但根目录的 Vite 6 被 React 插件解析，插件选择了错误的转换路径；显式排除 node_modules 也缺失。版本对齐后，手动挂载组件又暴露“找不到 Fast Refresh preamble”。Astro 的 before-hydration hook 不会替这类手动 `createRoot` 加载执行。

**修复**：显式依赖 Vite 8.2.1 / plugin-react 5.2.0；React 排除 node_modules；仅开发模式在动态 TSX 加载前 await 插件官方 preamble；移除无效的旧 prebundle 排除 workaround。新增依赖解析一致性测试。生产产物无 Fast Refresh 标记，开发/生产都实测打开并聚焦输入框。

### P1 — 锁文件安全通告与未封闭的发布流程

**事实**：官方 audit 匹配 `fast-uri@3.1.6`、`brace-expansion@5.0.9`、`devalue@5.8.1` 的 high 级通告。这表示匹配已知漏洞版本，不证明本站每项都可被利用。默认镜像的 audit API 返回 405，不能将其误记为无漏洞。

**修复**：分别更新至 3.1.8 / 5.0.12 / 5.9.4；没有盲目 `audit fix --force` 或升级框架大版本。显式官方 registry 审计命令加入 GitHub CI。Node 主版本与 `.nvmrc`/CI 对齐为 22；npm 版本记录为实测的 10.9.8。

Vercel 的 buildCommand 从仅 build 改为 `npm run ci`，直接要求单元测试、类型检查、历史 URL 和产物检查通过。GitHub workflow 最小读取权限、超时和同分支取消旧任务。平台是否覆盖命令、是否等待独立安全审计仍需线上核对。

### P1 — 聊天输入与资源消耗边界

- 路由拒绝非 JSON 和跨源浏览器请求；仍允许无 Origin 的 JSON 服务端客户端，Origin **不是认证**。
- 按真实 UTF-8 字节限长，并增加 5 秒整个请求体读取期限；不等待恶意流永不完成的取消承诺；严格拒绝坏 UTF-8；测试覆盖超限、停滞流、计时器清理。
- 限流 Map 限制 10,000 个活跃桶，满容量拒绝新桶而不是丢弃旧配额；修复窗口边界；代理 IP 只接受合法 IP。
- 408 前端提供手动重试，不自动重复调用模型；非 POST 方法通过框架检查后返回 405。
- Astro 会在路由之前拦截部分跨源表单，返回文本 403，而非应用 JSON。HTTP 冒烟记录了这一差异，未关闭框架安全功能。Vercel API 路径另配置 no-store；该部署响应头没有在本地服务器冒充验收。

### P2 — 检索体验与语义反馈

标题、摘要、标签和全部分类均可检索；NFKC + 不区分大小写 + 多关键词交集。修复原来分类列表能列出次分类、但筛选只看首分类的不一致。

搜索状态存入 `q`/`category` URL；复制、刷新和返回时恢复，replaceState 不为每个按键堆积历史。结果数量、年份计数、空状态、清除按钮、aria-pressed / live status 同步。按钮最小 44px；输入法组合期间不提前筛选。无 JS 时保留完整归档并隐藏无效搜索控件。

实测“资源”命中 4 篇，“资源 + iOS”命中 2 篇；刷新保持结果，清除回到 61 篇并聚焦搜索框。

### P2 — 焦点、日期与阅读可靠性

- 跳转正文链接原先固定 `top:-40px`，实际高度约 43px，导致未聚焦时露出边缘。改为依自身高度完全移出视口；main 可接收跳转焦点。
- 聊天关闭时 40ms 延迟聚焦与 CSS visibility transition 存在竞态，实际焦点落回 body。改为提交后管理焦点，移除 visibility 延迟，实测 Escape 后聚焦 FAB。回复完成不再抢走已移到页面的焦点；卸载取消本地请求。
- 聊天提示模型供应商数据传递风险；输入法组合 Enter 不发送；新增 320px 交互验收。
- 首页日期曾因本地时区显示 2024-04-29，而同篇文章/公开 URL 为 2024-04-30。只统一显示和归档分组的 UTC 口径，**没有改 frontmatter 或公开 URL**。
- 滚动进度从 width 改为 transform，并同步 aria-valuenow；目录标注当前位置；移动导航关联控制区域。
- 添加打印样式；打印对话、导航和侧栏不干扰正文，代码不依赖深色背景。打印纸面布局仍需实际打印预览复核。

### P2 — SEO、历史嵌入与长期回归门禁

404 改为 noindex，不输出错误 canonical。JSON-LD 转义 `<`，防止内容中的 `</script>` 结束 HTML script 元素。迁移到 Astro 的 unified processor API；明确解析 raw HTML 后再给图片/嵌入补语义与加载属性。

一篇历史文章含 HTTP iframe，HTTPS 页面不能可靠显示。仅在编译阶段替换为注明可能失效的外部链接，未改历史来源。Git 思维导图的同源 iframe 保留；响应头使用 SAMEORIGIN / frame-ancestors self，避免安全加固反而破坏它。

新增 `verify:site` 对实际输出做完整性检查及 JS 预算检查。4 个历史 HTML 附件明确列为现代页面结构豁免，仍检查本地引用；不自动豁免将来的新增附件。
